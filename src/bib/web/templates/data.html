Get the real BPASS data

BPASS releases are hosted by the team — this tool never redistributes them. The full releases are large (hundreds of GB with individual stellar models); the ingest manifest below tells you exactly which files you need.

  • BPASS v2.2.1 release page — population synthesis + stellar models (the primary release), with links to the hosted archives.
  • BPASS v2.3 release page — alpha-enhanced spectral synthesis extension.
  • bpass.auckland.ac.nz — project home, announcements, alternative hosting.
  • User manuals: v2.2 · v2.3 (OpenDyslexic versions on the tutorial page).

Ingest your download

Point the CLI at a directory containing BPASS release files (tarballs may stay packed — curated stellar models are extracted member-by-member): 

# create / upgrade the schema and load the bundled filter curves
bib init-db

# instant sandbox without any downloads (adds the warning banner)
bib demo-seed

# ingest the golden subset from your BPASS download
bib ingest --source /path/to/bpass_downloads

# or drive it with your own manifest of populations/models
bib ingest --source /path/to/bpass_downloads --manifest my_subset.yaml

# what ended up in the database?
bib info

The bundled manifest (src/bib/ingest/golden.yaml) defines the curated "golden subset": all 13 metallicities of the default IMF, IMF variants at two metallicities, the v2.3 alpha grids, HRD isocontours, and ~30 hand-picked stellar models. Copy and edit it to load more. Re-runs are idempotent; use --replace to force re-ingestion. Real data replaces the demo banner automatically once synthetic rows are removed.

The API

Everything the UI displays comes from /api/v1 — browse the interactive OpenAPI docs. A taste: 

# what's loaded, and every selector option
curl -s localhost:8000/api/v1/meta

# all binary populations at a tenth solar metallicity
curl -s "localhost:8000/api/v1/populations?pop_type=bin&z_label=z002"

# one SED: population 1 at 1 Gyr (age index 30), SMC dust, E(B-V)=0.1
curl -s "localhost:8000/api/v1/populations/1/sed?age_index=30&dust_law=smc&ebv=0.1"

# ...or as CSV at full native resolution
curl -s "localhost:8000/api/v1/populations/1/sed?age_index=30&format=csv" -o sed.csv

# AB magnitudes through bundled filters
curl -s "localhost:8000/api/v1/photometry?population_id=1&age_index=30&filters=sdss.g,sdss.r"

# stellar-model search (the future query-builder speaks this dialect)
curl -s "localhost:8000/api/v1/models?kind=primary&m1_min=10&m1_max=20"

Numbers in JSON responses are rounded to display precision; request CSV for full-precision spectra. The generic query builder ("all binaries with final mass 2–4 M☉ and log P < 1") will grow on top of these endpoints.
