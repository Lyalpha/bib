The API

Everything the UI displays comes from /api/v1{% if expose_docs %} — open the interactive API docs{% endif %}. Pick a population_id from the table above. Ages are log_age = log10(age/yr) on BPASS’s 0.1 dex grid from 6.0 (1 Myr) to 11.0 (100 Gyr). SED fetches are native resolution (the full 1 Å science grid).
