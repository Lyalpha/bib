About {{ branding.site_name }}

{{ branding.full_name }} v{{ version }} is a pedagogy-first web interface to the publicly released BPASS stellar population synthesis data products. It exists so that students, teachers and researchers can explore what stellar populations and binary stars do — interactively, in a browser — without first writing file parsers. Numbers shown are computed directly from ingested BPASS release files with full provenance; anything added for visual smoothness (interpolated animation frames, the demo dataset) is labelled as such.

Credit where it is due

BPASS is the work of J. J. Eldridge (University of Auckland), E. R. Stanway (University of Warwick) and collaborators, who develop the models and release the data on a best-effort basis under CC BY-NC 4.0. {{ branding.site_name }} is an independent interface: it is not an official BPASS product, and any bugs here are ours, not the BPASS team's. For science-grade use, always consult the manuals and release papers.

  • Bundled filter curves: retrieved from the Spanish Virtual Observatory Filter Profile Service — please cite Rodrigo, Solano & Bayo (2012) and Rodrigo & Solano (2020) if the filter set matters to your work.

Built with

FastAPI, SQLAlchemy and PostgreSQL on the back end; Plotly.js, htmx and Alpine.js (all vendored, no CDN) on the front end; numpy and astropy for the science core, with dust laws via the dust_extinction package (Gordon 2024) plus an inline Calzetti (2000) implementation; packaged with uv; runs in Podman or Docker, or bare. Colour branding is configurable per deployment via branding.yaml.
